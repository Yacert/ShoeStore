# ShoeStore — Boutique de chaussures en ligne

Projet de fin de module — Programmation Web (PHP) | ISMAGI 2025-2026

## Description
Site e-commerce de vente de chaussures en ligne développé en PHP, HTML, CSS et MySQL. Permet aux utilisateurs de consulter un catalogue de produits, gérer un panier via les sessions PHP, créer un compte et valider des commandes. Base de données gérée avec PDO et phpMyAdmin sous XAMPP.

## Technologies utilisées
- PHP (sessions, PDO)
- MySQL / phpMyAdmin
- HTML / CSS (Responsive)
- XAMPP (Apache + PHP + MySQL)

## Fonctionnalités
- Catalogue de chaussures avec images et prix
- Panier d'achat (ajout, suppression, total)
- Création de compte et connexion utilisateur
- Validation de commande
- Interface responsive
- Protection contre les injections SQL (PDO + requêtes préparées)

## Installation
1. Installer XAMPP
2. Copier le dossier `shoestore/` dans `htdocs/`
3. Importer `shoestore.sql` dans phpMyAdmin
4. Accéder à `http://localhost/shoestore`
